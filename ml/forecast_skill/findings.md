# Forecast-skill backtest: Kp(t+3h) / Dst(t+3h) by storm phase

Generated by `ml/forecast_skill.py`, aligned on the 75 DONKI-cataloged
geomagnetic storms in the held-out test period (2021-2025) using the same
event-alignment/aggregation code SEA (section 5) uses on raw Dst -- here
applied to the model's prediction error instead.

## Why this exists

A "live current forecast" tile was the original plan, but it doesn't fit
the rest of this dashboard: it would only be meaningful if continuously
recomputed from real-time solar wind data, which makes it functionally
the same live-readings feature that was already descoped (section
4/7/8) -- and NOAA SWPC already publishes its own operational Kp forecast,
so it would mostly duplicate an existing public tool. This backtest is the
retrospective-analysis framing that's actually consistent with SEA and the
historical explorer: given known historical storms, how well would the
model have forecast each one.

## Headline result: forecast error is not uniform through a storm

Aggregate test-set metrics (RMSE/MAE from `ml/train.py`) describe average
performance across all conditions, most of which are quiet. Aligning error
on storm onset shows a very different picture during the minority of hours
that actually matter operationally:

| | quiet-time baseline (mean \|error\|) | worst point (mean \|error\|) | when |
|---|---|---|---|
| Kp(t+3h) | ~0.65-0.7 | **2.50** (~3.6x) | offset -3h (just before onset) |
| Dst(t+3h) | ~5.5-6 nT | **20.9 nT** (~3.6x) | offset 0h (at onset) |

Both targets are roughly **3.5x worse right around storm onset** than
their steady-state error -- the model is meaningfully worse exactly when
a forecast would matter most. Error decays back to baseline over
~20-30h (Kp) to ~40-50h (Dst) after onset.

## Bias, not just magnitude

The signed-error curves show *systematic under-prediction* of storm
severity going into onset, not just noisier predictions:

- **Dst**: strongly positive bias (+16 nT) at offset -1h/0h -- "predicted
  minus actual" being positive means the model's predicted Dst is less
  negative than reality, i.e. it under-predicts how deep the storm gets,
  right as the sudden decrease happens.
- **Kp**: strongly negative bias (-2.5) at offset -3h -- the model
  under-predicts the Kp ramp-up 3 hours before the reported storm onset
  time (DONKI's start_time is keyed to a specific Kp threshold reading,
  which happens on the 3-hourly Kp cadence rather than continuously).

This is the textbook "sudden commencement" forecasting problem: a
lagged-feature regression model trained on smoothly-varying solar wind
history is structurally biased toward predicting continuation of recent
conditions, so a sharp, sudden intensification is exactly the case it
misses hardest -- consistent with why persistence-beating models still
need much more sophisticated architectures (e.g. models with direct
CME/shock-arrival features) to substantially close this specific gap.
